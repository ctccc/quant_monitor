# 数据源方案：免费接口调研、映射与稳定性策略

> 配套文档：[任务拆解与路线图](PLAN.md) · [技术架构](ARCHITECTURE.md)
>
> ⚠️ 本文所有接口均为各网站的公开数据接口（akshare 等开源库的底层同款），**未经官方承诺**，
> 字段与地址可能变化。开工前务必在本机运行 `python scripts/check_datasources.py` 逐一验证。
> 仅供个人研究使用，请遵守各网站服务条款，控制请求频率。

## 1. 数据源全景与取舍

| 数据源 | 类型 | 成本/权限 | 结论 |
|--------|------|-----------|------|
| 东方财富（push2 系列接口） | 实时快照、板块、资金流、涨停池、分时、K线 | 免费、无需注册 | ✅ **主力源**：一家覆盖本项目 80% 需求 |
| 腾讯行情 `qt.gtimg.cn` | 个股实时快照 | 免费 | ✅ 快照备用源（历史稳定性极好） |
| 新浪行情 `hq.sinajs.cn` | 个股实时快照 | 免费（需带 Referer 头） | ✅ 快照备用源 2 |
| akshare | 上述各站的开源爬虫聚合库 | 免费 | ✅ 仅用于低频数据（历史K线、新闻、龙虎榜、交易日历） |
| tushare pro | 结构化数据 API | 注册积分制，常用接口要求高积分 | ❌ 放弃——上一版卡壳点，坚决不再依赖 |
| Level-2 行情（逐笔委托/十档盘口） | 深度数据 | 付费 | ❌ 不做（见 §5 能力边界） |
| 交易所官方接口 | 披露/公告 | 免费但格式杂 | ⏸ P4 再评估，公告先用东财/akshare 渠道 |

**A 股免费 Level-1 快照的真相**：东财/腾讯/新浪的快照都是实时的（非 15 分钟延迟），刷新粒度约 3 秒。
对秒级打板党不够，对"识别主线板块 + 异动提醒"的超短盯盘完全够用。

## 2. 核心接口清单（按功能模块映射）

> 下列 URL 与字段号来自 akshare 底层实现与公开资料，以体检脚本实测为准。

### 2.1 全市场实时快照（支撑 F3.1 实时引擎 / F3.2 板块热度 / F3.5 自选盯盘）

```
GET https://push2.eastmoney.com/api/qt/clist/get
    ?pn=<页码>&pz=200&po=1&np=1&fltt=2&invt=2&fid=f3
    &fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048   # 沪深主板+创业板+科创板+北交所
    &fields=f2,f3,f5,f6,f8,f10,f12,f14,f22,f62,f100
```

| 字段 | 含义 | | 字段 | 含义 |
|------|------|-|------|------|
| f12 | 代码 | | f8 | 换手率 |
| f14 | 名称 | | f10 | 量比 |
| f2 | 最新价 | | f22 | 涨速（分钟级） |
| f3 | 涨跌幅 | | f62 | 主力净流入 |
| f5/f6 | 成交量/额 | | f100 | 所属行业 |

一页 200 只，全市场约 27 页；盘中 3–5 秒一轮 ≈ 安全频率。**这是整个盘中模块的心脏接口。**

### 2.2 板块行情与资金流（支撑 F1.3 / F3.2）

同 `clist` 接口，换 `fs` 参数：

- 行业板块：`fs=m:90+t:2`；概念板块：`fs=m:90+t:3`
- 资金流字段：`f62` 主力净流入、`f66` 超大单、`f72` 大单、`f184` 主力净占比
- 按 `fid=f62` 排序即得"主力净流入排行"
- 板块成分股：`fs=b:<板块代码>`（如 `b:BK0475`）
- 近 N 日板块资金趋势：盘后每日落库自算（比调历史接口更可靠）

### 2.3 涨停/炸板/跌停池（支撑 F1.2 / F3.4）

```
GET https://push2ex.eastmoney.com/getTopicZTPool     # 涨停池
GET https://push2ex.eastmoney.com/getTopicZBPool     # 炸板池
GET https://push2ex.eastmoney.com/getTopicDTPool     # 跌停池
    ?ut=<东财网页公共参数，非密钥，取值见 scripts/check_datasources.py>&dpt=wz.ztzt
    &Pageindex=0&pagesize=300&sort=fbt:asc&date=<YYYYMMDD>
```

返回含：首次封板时间、最后封板时间、封单资金、炸板次数、连板数（`lbc`）、所属行业——涨停复盘所需字段一应俱全。akshare 对应 `stock_zt_pool_em` 等函数，可作为字段对照参考。

### 2.4 个股分时与历史 K 线（支撑看板图表 / F4.1 回放）

- 分时：`https://push2his.eastmoney.com/api/qt/stock/trends2/get?secid=1.600519&ndays=1&...`（secid 前缀：`1.`=沪，`0.`=深/北）
- 日K（后复权可选）：`https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=...&klt=101&fqt=1&...`
- 低频场景直接用 akshare：`ak.stock_zh_a_hist()`

### 2.5 快照备用源（支撑 F0.1 降级路由）

| 源 | 调用方式 | 注意点 |
|----|----------|--------|
| 腾讯 | `GET https://qt.gtimg.cn/q=sh600519,sz000001,...`（一次可 ~60 只） | 返回 GBK 编码，`~` 分隔 |
| 新浪 | `GET https://hq.sinajs.cn/list=sh600519,...` | **必须带** `Referer: https://finance.sina.com.cn`，GBK 编码 |

备用源只保底自选股与指数快照（几十只规模），不承担全市场轮询。

### 2.6 低频数据（akshare 渠道）

| 需求 | akshare 函数（以当前版本文档为准） | 用于 |
|------|-------------------------------------|------|
| 财经新闻 | `stock_news_em` / `stock_info_global_cls` 等 | F2.1（现 monitor.py 已在用） |
| 龙虎榜 | `stock_lhb_detail_em` | F1.4 |
| 交易日历 | `tool_trade_date_hist_sina` | F0.2 |
| 历史K线 | `stock_zh_a_hist` | 图表/回放 |
| 美股/A50/汇率快照 | `index_us_stock_sina` 等 | F2.4 |

## 3. 稳定性策略（把"接口挂了"从灾难降级为小事）

1. **适配层隔离**：业务代码只依赖统一数据模型，每个源一个适配器文件（ARCHITECTURE.md §3）。
2. **双源保底**：快照类数据主源东财、备源腾讯/新浪，router 自动切换。
3. **限速与伪装**：全局令牌桶（默认 ≤ 5 req/s）、正常浏览器 UA、必要的 Referer；绝不并发轰炸。
4. **体检脚本常态化**：接口异常时先跑 `check_datasources.py` 定位是"哪个源的哪个接口"坏了，而不是盲目翻代码。
5. **每日落库**：盘后把当天所有关键数据存 SQLite/Parquet——历史数据永远查本地，不依赖任何历史接口的可用性。

## 5. 能力边界（免费数据做不到的事，提前认清）

- ❌ 逐笔成交、十档盘口、委托队列 —— 需要付费 Level-2，本项目所有功能设计均不依赖。
- ❌ 秒级以下的极速打板信号 —— 3 秒快照粒度决定了警报延迟下限约 5–10 秒。
- ❌ 盘中每一秒的历史回溯 —— 只能回放我们自己存下来的 3–5 秒快照（从 M3 上线那天起积累）。
- ⚠️ 新闻/公告的完整性 —— 免费渠道有遗漏和延迟，简报定位是"辅助"而非"全量"。
