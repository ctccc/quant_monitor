# AI 辅助决策层设计（融合 Trading Agent 思路）

> 配套文档：[任务拆解与路线图](PLAN.md) · [技术架构](ARCHITECTURE.md) · [数据源方案](DATA_SOURCES.md)
>
> 背景：此前另一个"LLM 分析新闻/资金流/异动并给出买卖决策"的项目卡在两点——
> ① LLM 推理太慢，跟不上短线节奏；② 决策黑盒 + 幻觉，回撤不可控。
> 本文档给出把该思路并入本项目的方式，以及为什么必须这样分层。

## 1. 核心结论：快慢分层，而不是"AI 产品 vs 传统产品"二选一

- **快系统 = 传统规则引擎**（本项目 P0–P3 的全部内容）：全市场扫描、异动检测、
  涨停池、警报、风控红线。确定性计算，毫秒-秒级，可回测、可审计。
- **慢系统 = LLM 参谋层**（本文档，P5）：读快系统产出的结构化事实，做语言层面的
  归纳与解读。分钟级、全部异步，**不在任何实时回路里，永远没有下单权**。

上一个项目的两个卡点在这个分层下自动消失：

| 卡点 | 架构学解释 | 分层后的答案 |
|------|-----------|--------------|
| LLM 时效性滞后 | LLM 推理秒级~十几秒级，A 股快照 3 秒一跳，物理上追不上 | 时间敏感的活全部归快系统；LLM 只干"晚几分钟也不影响价值"的活（简报、归因、复盘） |
| 幻觉/黑盒/回撤不可控 | LLM 直接给买卖决策 = 不可审计、不可回测、无法约束 | LLM 降级为"带引用的参谋意见"；风控红线硬编码在规则里；下单权在人 |

## 2. 任务分工表

| 任务 | 引擎 | 时延 | 对应功能 |
|------|------|------|----------|
| 全市场扫描 / 异动检测 / 涨停池 | 规则 | 秒级 | F3.1–F3.4 |
| 警报触发与推送 | 规则 | 秒级 | F3.3 |
| 风控红线（仓位/止损提醒） | 规则（硬编码，不经 LLM） | — | P4 交易日志配套 |
| 新闻解读、重要性分级 | LLM | 分钟级 | F2.1 增强 |
| 板块主线归纳（"今天资金在讲什么故事"） | LLM | 盘前/盘中异步 | F2.5 / F3.2 增强 |
| 盘前作战简报成文 | LLM | 盘前一次 | F2.5 增强 |
| 异动归因（警报后补充"它为什么动：关联消息/板块联动"） | LLM | 警报后异步 ≤2 分钟 | F3.3 增强 |
| 盘后复盘叙事 + 笔记初稿 | LLM | 盘后一次 | F1.5 增强 |
| 买卖决策与执行 | **人**（远期至多"模拟盘 + 可回测规则"，仍与 LLM 无关） | — | — |

## 3. 防幻觉三铁律（工程强制，不靠提示词自觉）

1. **只读结构化事实**：LLM 的输入是本系统快系统算好的 JSON（情绪指标、板块资金流
   排行、涨停梯队、警报记录、新闻原文），**禁止让它凭训练记忆给出任何行情数字**。
   它没见过的数据，就不该出现在它嘴里。
2. **输出结构化 + 强制引用**：LLM 输出固定 JSON schema，每条结论必须携带
   `evidence` 字段指向输入数据的具体条目；渲染时可点开溯源。无引用的结论直接丢弃。
3. **参谋定位，永不执行**：所有 AI 产出在 UI 上带明显的"AI 参谋意见"标识；
   系统不存在任何"LLM 输出 → 下单"的代码路径，模拟盘接入（若做）也只接规则信号。

## 4. 模型接入设计

```
quant_monitor/llm/
├── client.py      # OpenAI 兼容风格的统一客户端(base_url + api_key 可配)
├── prompts/       # 每个任务一个提示词模板文件,版本化管理
└── tasks/         # 简报生成 / 异动归因 / 复盘叙事,每任务一个模块
```

- **模型无关**：DeepSeek、Qwen、Claude、GLM 等兼容 OpenAI 风格 API 的模型均可，
  `config.yaml` 里改 `base_url` + `model` 即换。
- **便宜模型足够**：任务本质是"读表格写摘要"，非深度推理；用 DeepSeek/Qwen 级别
  的 API，每天盘前+盘后+若干次归因调用，成本在分钱到几毛钱量级。
- **降级友好**：LLM 层整体可关（`llm.enabled: false`），关掉后系统就是纯规则版
  工作站，所有核心功能不受影响——这也是验收标准之一。

## 5. 里程碑挂接与顺序警示

AI 层编号为 **P5**，对应里程碑 **M5**，严格排在 M1–M3 之后：

| 阶段 | 内容 | 验收标准 |
|------|------|----------|
| M5a | llm/ 适配层 + 盘后复盘叙事（最安全的首个场景，错了也无盘中影响） | 关闭 LLM 系统功能完整；开启后复盘页多出"AI 复盘摘要"卡片，每条结论可溯源 |
| M5b | 盘前简报成文 + 新闻重要性分级 | 9:26 前产出带引用的简报 |
| M5c | 盘中异动归因（异步） | 警报出现后 ≤2 分钟补充归因卡片，不阻塞警报本身 |

**顺序警示**：先做 AI 层、后做数据与规则骨架，就是上一个 trading agent 项目
烂尾的路径——LLM 没有干净的事实源可读，只能瞎猜（幻觉），又被迫塞进实时回路（延迟）。
本项目必须反过来：**M1–M3 的快系统是 AI 层的地基，不是可选项。**
